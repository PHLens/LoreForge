# Inbox

Temporary location for unsorted captures and staged packages.

Use this area when knowledge may be durable but the correct domain, card, or source location is unclear.

## Layout

```text
capture/      Quick notes from ingest mode=capture
ingest/       Staged packages from external sources
writeback/    Staged packages from conversation/query synthesis
```

Processed packages should include `manifest.md` plus candidate notes or deltas. Ordinary captures do not need a manifest until processed.
