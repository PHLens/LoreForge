# Wiki Maintenance View

Use this view for linting, indexing, restructuring proposals, and cleanup.

## Load First

- `AGENTS.md`
- `00_System/Vault Map.md`
- `00_System/Schema.md`
- `00_System/Wiki Log.md`
- Relevant domain maps

## Allowed Without Confirmation

- Read-only reports
- Proposed index or schema fixes

## Requires Confirmation

- Regenerating indexes
- Appending wiki log entries
- Moving notes
- Deleting notes
- Rewriting stable notes
- Changing schema or task views
- Promoting staged content

## Log Rule

Read-only maintenance normally does not write the wiki log. Log a lint pass only when it has meaningful findings or produces an approved maintenance follow-up.
