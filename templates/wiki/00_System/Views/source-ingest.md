# Source Ingest View

Use this view when processing a new article, paper, document, or source note.

## Load First

- `AGENTS.md`
- `00_System/Vault Map.md`
- Target domain map
- Relevant `+Wiki Index.md` sections
- Source material

## Workflow

1. Preserve source provenance.
2. Identify reusable concepts.
3. Check existing cards before creating new ones.
4. Create a staged package with `manifest.md` before stable cards.
5. Log substantive package creation in `00_System/Wiki Log.md`.
6. Propose promotion only after review.
7. Use `promote` for stable notes, index updates, staging archive, and promotion log entries.

## Writeback Rule

New source-derived knowledge starts staged. Do not promote without confirmation.
